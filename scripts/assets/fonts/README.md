# Fonts

`Geist-Variable.ttf` is the Geist variable font (weight axis 100 to 900, version 1.800), the same family the Kumia Labs site uses.

- **Source:** the Latin subset that `next/font/google` ships with the site, converted from WOFF2 to TTF once so Pillow can read it. Upstream project: https://github.com/vercel/geist-font
- **Copyright:** Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font)
- **License:** SIL Open Font License, Version 1.1. The full text is in [`OFL.txt`](./OFL.txt) in this folder (copied unchanged from the upstream repository). Redistribution with this repository is permitted under those terms.
- **Coverage:** basic Latin plus common punctuation (curly quotes, en/em dash, middle dot, ellipsis, multiplication sign). Titles in other scripts need a different font.
